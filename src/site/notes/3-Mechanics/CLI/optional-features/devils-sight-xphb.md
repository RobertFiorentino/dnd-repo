# Devil's Sight
*Source: Player's Handbook (2024) p. 155*  

**Prerequisite**: 2nd Warlock

You can see normally in [[3-Mechanics/CLI/rules/variant-rules/dim-light-xphb\|Dim Light]] and [[3-Mechanics/CLI/rules/variant-rules/darkness-xphb\|Darkness]]—both magical and nonmagical—within 120 feet of yourself.
