# Puzzle Box
*Mysterious box covered in runes*  

### To Open the Box

Requires two successful checks:
- DC 12 Sleight of Hand
- DC 12 Arcana
Person attempting must have proficiency in Tinkerer's Tools
May receive help (Advantage) by another character with proficiency in Tinkerer's tools

### The Cryptex

Inside the box is yet another puzzle, a Cryptex that requires a code to open.

Once per day, successful Sleight of Hand and Arcana checks will reveal new clues but in the end, they will need to guess the secret code DNEIRF (friend backwards because ancient Netheril wrote right to left).
